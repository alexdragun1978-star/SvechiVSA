СВЕЧИ И VSA — Android-проект, версия 0.3

Сборка версии 0.3. Код приложения и учебный интерфейс находятся в app/src/main.

Что входит:
- Русский интерфейс и офлайн-уроки по свечам, VSA и рыночному контексту.
- Практические вопросы с объяснениями; счёт и прогресс сохраняются на устройстве.
- Учебный график USD/JPY H1: движение по одной свече вперёд/назад, свечи и столбцы объёма.
- Импорт CSV-файлов с историческими OHLCV-данными через системный выбор файла Android.
- Пример CSV-колонок: Date,Open,High,Low,Close,Volume. Также поддерживаются timestamp,open,high,low,close,volume.
- Учебная последовательность на графике помечена как демонстрационная, она НЕ является реальной историей рынка.

Реальные исторические USD/JPY:
1. Откройте в приложении раздел «График».
2. Получите USD/JPY H1 или H4 CSV из Dukascopy Historical Data Export:
   https://www.dukascopy.com/swiss/english/marketwatch/historical/
3. Импортируйте CSV через «Загрузить реальные исторические данные».
4. Проверьте часовой пояс, источник и тип объёма. На Forex объём часто тиковый и зависит от поставщика.

Сборка APK:
1. Установить Android Studio.
2. Открыть папку SvechiVSA как проект.
3. Дождаться синхронизации Gradle и установки Android SDK Platform 35.
4. Build -> Build Bundle(s) / APK(s) -> Build APK(s).
5. APK: app/build/outputs/apk/debug/app-debug.apk

Минимальная версия Android: 6.0 (API 23). Подходит для Samsung A50 с Android 11.

Важно: это учебный инструмент, не торговый совет и не гарантия результата. Импортированный CSV остаётся на устройстве; приложение не загружает его на сервер.

Автоматическая сборка APK через GitHub Actions (без Android Studio):
1. Создайте пустой репозиторий GitHub и загрузите в него содержимое папки SvechiVSA.
2. Откройте вкладку Actions и разрешите запуск workflows, если GitHub спросит.
3. Запустите workflow «Build Android APK» кнопкой Run workflow (или отправьте commit в ветку main).
4. После успешной сборки откройте запуск workflow и скачайте artifact SvechiVSA-debug-apk.
5. Внутри архива будет app-debug.apk. Перенесите его на телефон и установите.


Проверка текущего результата: исходный проект подготовлен; готовый APK в этом архиве НЕ находится. Для получения APK workflow должен успешно выполниться в GitHub Actions. Не устанавливайте APK из неизвестных сторонних источников.
